# Require GitHub coding evidence

Every searchable Profile must represent an adult with a personal GitHub account and evidence of coding through an owned non-fork repository, a public contribution within the last 12 months, or verified private-account ownership with Member attestation. Humans identifies accounts by immutable GitHub user ID, treats renames as continuity, suppresses known minors immediately, and suppresses unresolved inaccessible accounts after a 30-day grace period.
