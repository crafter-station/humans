# Deploy the product across Vercel and Cloudflare

Humans will run its Next.js application on Vercel and its Hono HTTP API, Scalar API documentation, and stateless Streamable HTTP MCP endpoint on Cloudflare Workers. Cloudflare is the authoritative DNS provider for `humns.co`: the apex web hostname is a DNS-only record for Vercel, while `api.humns.co` is a Worker Custom Domain with Cloudflare-managed DNS and TLS. Production browser search calls that API hostname with a short-lived Clerk session token. Immutable Vercel deployments call their environment's pinned `workers.dev` origin so Preview and staged Production acceptance cannot accidentally cross release boundaries. Server-only web operations remain same-origin Next.js route handlers. Trigger.dev owns long-running enrichment, Neon hosts PostgreSQL with pgvector, and Drizzle uses the Neon adapter and Drizzle Kit-generated migrations rather than hand-authored migration files. Drizzle cannot declare PostgreSQL extensions, so extension DDL is generated from a declarative extension list into a Drizzle Kit custom migration; engineers do not edit the resulting SQL artifacts.
