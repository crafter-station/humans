# Issue tracker: GitHub

Issues and specs live in `crafter-station/humans` on GitHub. Use the `gh` CLI for all operations.

## Conventions

- Create, read, list, comment on, label, and close work with `gh issue`.
- Infer the repository from `origin` when running inside this clone.
- Pull requests are not a triage request surface.
- When a skill says to publish to the issue tracker, create a GitHub issue.
- When a skill says to fetch a ticket, read the issue and its comments and labels.
- Use GitHub sub-issues and native issue dependencies for wayfinding when available.
- Fall back to task lists and `Blocked by: #...` text only when native relationships are unavailable.
