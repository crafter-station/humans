# Domain Docs

Humans is a single-context repository.

Before exploring or changing the codebase, read the root `CONTEXT.md` and the relevant ADRs under `docs/adr/`. Proceed silently if either is absent.

Use the glossary's canonical terms in issues, specs, code, and tests. Avoid synonyms that `CONTEXT.md` explicitly rejects. Surface any proposed work that contradicts an ADR instead of silently overriding it.

The authoritative layout is:

```text
/
|-- CONTEXT.md
`-- docs/adr/
```
